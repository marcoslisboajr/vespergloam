# VESPERGLOAM — A Descida

Roguelite de texto em dark fantasy, inspirado em Elden Ring e Buriedbornes. Você desce andar por andar por zonas cada vez mais fundas, enfrenta criaturas em combate por turnos, acumula Máculas e tenta sobreviver às Três Vigílias.

**[▶ Jogar no navegador](https://marcoslisboajr.github.io/vespergloam/)**

## Destaques

- **Um arquivo só:** HTML, CSS e JavaScript puros em `index.html`, sem framework nem build.
- **Combate por turnos com a matemática aberta:** a narradora, Sétima, pode mostrar o cálculo de cada golpe ou rodar no modo rápido.
- **Bestiário** que vai se preenchendo conforme as criaturas aparecem.
- **Run salva e progresso permanente** no `localStorage`, com fallback quando o armazenamento está bloqueado.
- **Finais escondidos** e textos com voz própria, em português.

## Rodar localmente

Abra o `index.html` em qualquer navegador moderno.
